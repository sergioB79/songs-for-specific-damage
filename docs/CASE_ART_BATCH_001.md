# CASE ART // BATCH 001

These five images establish the first visual evidence system for SSD.

## Editorial assignments

- **F#ck This! I Am Out.** — cinematic documentary evidence; not every SSD case should look like pop-art.
- **Pizza, Pasta, Puttana** — punk collage / travel debris / cultural overload.
- **Grandma Took My Acid** — flagship Cosmic Malfunction artwork; pseudo-scientific metrics embedded in the image.
- **Punching Ghosts** — Controlled Rage / Punishment energy; diagrammatic comic evidence.
- **Cows Wearing High Heels** — flagship Absurd Joy artwork; ridiculous subject presented with institutional confidence.

## Usage

Full artwork: case pages, homepage hero moments, editorial interruptions.

Cropped artwork: index cards and secondary placements.

Do not force all 125 cases into the same art template. SSD should look like an archive assembled from incompatible forms of evidence, held together by recurring labels, case IDs, damage metadata and deadpan institutional copy.
